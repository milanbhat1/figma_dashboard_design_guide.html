# 🎬 My Watch Dashboard

A simple dashboard I made to keep track of all the movies and series I've watched 
during my college years (Jul 2024 – Apr 2026). Basically tired of forgetting what 
I watched, so I built this.

---

## What is this?

It's a personal watch tracker. Nothing fancy — just a clean dark-themed HTML page 
that shows everything I've watched, with some filters to sort by semester, type 
(movie/series), and genre.

Live site → https://milanbhat1.github.io/figma_dashboard_design_guide.html

---

## Stats (as of Apr 2026)

- Total titles watched: **209**
- Movies: **170** (81.3%)
- Series: **39** (18.7%) — 887 episodes combined
- Tracking since: **3rd semester**

Top genres: Action, Drama, Animation, Comedy, Sci-Fi, Thriller

---

## Features

- Filter by semester (3rd to 6th sem)
- Filter by type — movie or series
- Filter by genre
- Shows episode count and genre tags for each title
- Dark theme, desktop layout (1440×900)

---

## Tech used

Plain HTML, CSS, and JS. No frameworks, no libraries.

---

## How to run

Just clone it and open index.html in a browser. That's it.

```bash
git clone https://github.com/milanbhat1/figma_dashboard_design_guide.git
```
